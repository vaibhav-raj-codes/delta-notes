# including css into html file

visit the official [bootstrap.com](https://getbootstrap.com/docs/5.3/getting-started/introduction/)

copy paste the cdn link for style and script =>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.7/dist/css/bootstrap.min.css">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.7/dist/js/bootstrap.bundle.min.js"></script>


# cdn - content delivary network (provides data from nearest server)

# containers and layouts
# containers
containers - used  to contain, pad  and (sometimes) center the content within them

use .container for making container classes with different widths
[containers]https://getbootstrap.com/docs/5.3/layout/containers/

# button (component)
use .btn base class to make any button a bootstrap button

[buttons](https://getbootstrap.com/docs/5.3/layout/containers/)

# badges (component)
badges is the part where we get notifications in whatsapp like 5 unread messages.
we can add similar number in any of our html component using badges.

[badge](https://getbootstrap.com/docs/5.3/components/badge/)

# alerts (component)
alerts are temporary block of code/ line that will display some message.

[alert](https://getbootstrap.com/docs/5.3/components/alerts/)

# button group (component)
buttons can be grouped within a div class="btn-group". just drag all the buttons into this class.

[button group](https://getbootstrap.com/docs/5.3/components/button-group/)

# navbar (component)
nav bars is the section which connects the different parts of the website

[navbar](https://getbootstrap.com/docs/5.3/components/navbar/)

# dropdown (component)
to create a dropdown menu

[dropdown](https://getbootstrap.com/docs/5.3/components/dropdowns/)

# cards (component)
cards can be used to display some static information usually with a photo and a description

[cards](https://getbootstrap.com/docs/5.3/components/card/)

# grid (responsive) (layout)
we can make a grid in bootstrap. In bootstrap each grid for every row it has 12 columns. so 2 classes .col-6 and .col-6 will divide the row equally in 2 parts.

[grid](https://getbootstrap.com/docs/5.3/layout/grid/)

grid options- below a certain size the grid will collapse into a single column. for example .col-sm- will collapse at size 576px.

# grid (column) (layout) vertical alignment
we can do things like aligning items or self to center, start, end etc just like flexbox.
[column](https://getbootstrap.com/docs/5.3/layout/columns/)

# forms (component)
we can use this to make forms, mainly used in login page.
[forms](https://getbootstrap.com/docs/5.3/forms/overview/)

# forms dropdown (component)
we can make different dropdowns inside the forms, using .select div and multiple .option divs inside .select div

[dropdown in forms](https://getbootstrap.com/docs/5.3/forms/select/)

# forms layout (component)
we can set different forms layouts in bootstrap
[forms layout](https://getbootstrap.com/docs/5.3/forms/layout/)

# utlities
we can use different utilities such as spacing 

[utilities](https://getbootstrap.com/docs/5.3/utilities/spacing/)
